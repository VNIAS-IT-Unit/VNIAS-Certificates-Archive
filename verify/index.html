Verification desk

Check a certificate

Enter the identifier printed on the certificate. Dashes are optional, and the search is not case-sensitive.

Format: VNIAS · programme code · year · unique code.

If you cannot find the certificate

Use the QR code

Scanning the QR code on the certificate opens its record directly and removes any risk of transcribing the ID incorrectly.

Check confusable characters

VNIAS identifiers never contain the letters I, L, O or U. If you read one of those, it is a 1 or a 0.

Report a suspected forgery

If a certificate presents an ID that does not resolve here, contact vitanova.science@gmail.com.
